# Release status

Version 1.1.0 is a preview candidate. Automated regression tests have passed in review environments; this does not establish production readiness on every host.

Before a stable production release, verify real systemd installation and rollback on a disposable host, backup restoration, restricted dashboard SSH access, and Discord permissions and behavior in an isolated test channel. Private memory/retrieval remains disabled by default. Hardware-specific GPU scripts require separate operator review.
